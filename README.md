# Yashvi Enterprise — Blog Management System (Laravel)

A blog-only website with a secure admin panel for adding, editing, and deleting blog posts.

## What's included

- **Admin Login** (session-based, `Auth::attempt`)
- **Admin Dashboard** with stats (total / published / draft blogs)
- **Full Blog CRUD** — Add, Edit, Delete, List (with search + pagination), image upload, CKEditor rich text content
- **Public Blog Website** — homepage listing + single blog page with view counter and related posts
- **Database**: Laravel migrations (`database/migrations`) + seeders (`database/seeders`) **and** a ready-made SQL dump (`database/sql/yashvi_enterprise.sql`) if you'd rather import directly
- Clean, modern Bootstrap 5 design (purple/gold admin theme, card-based public blog layout)

## Setup Instructions

This folder contains the **application code** (models, controllers, views, routes, migrations, seeders) — not a full fresh Laravel skeleton (vendor files, artisan bootstrapping, etc.), since that has to be generated by Composer on your machine. Two steps:

### 1. Create a fresh Laravel project and drop these files in

```bash
composer create-project laravel/laravel yashvi-enterprise
cd yashvi-enterprise
```

Then copy/overwrite these folders from this package into your new project (replace the matching folders):

```
app/Models/
app/Http/Controllers/
routes/web.php
database/migrations/   (add the two blog/user migration files — remove Laravel's default ones with the same table names if duplicated)
database/seeders/
resources/views/
composer.json           (merge — or just run `composer require` for nothing extra, base Laravel already has everything needed)
.env.example             (copy values into your real .env)
```

### 2. Configure environment

```bash
cp .env.example .env
php artisan key:generate
```

Edit `.env` and set your database credentials:

```
DB_DATABASE=yashvi_enterprise
DB_USERNAME=root
DB_PASSWORD=your_password
```

### 3. Set up the database — choose ONE option:

**Option A — Migrations + Seeder (recommended)**
```bash
php artisan migrate
php artisan db:seed
```

**Option B — Import the SQL file directly**
Import `database/sql/yashvi_enterprise.sql` into MySQL via phpMyAdmin or:
```bash
mysql -u root -p < database/sql/yashvi_enterprise.sql
```
(This already creates the database, tables, admin user, and 3 sample blog posts.)

### 4. Link storage (for blog image uploads)

```bash
php artisan storage:link
```

### 5. Run the app

```bash
php artisan serve
```

- Public blog: `http://localhost:8000/`
- Admin login: `http://localhost:8000/login`
- Admin dashboard: `http://localhost:8000/admin/dashboard`
- Manage blogs: `http://localhost:8000/admin/blogs`

## Database Schema

**users**
| Column | Type |
|---|---|
| id | bigint, PK |
| name | varchar |
| email | varchar, unique |
| password | varchar (hashed) |
| remember_token | varchar |
| timestamps | |

**blogs**
| Column | Type |
|---|---|
| id | bigint, PK |
| user_id | bigint, FK → users.id |
| title | varchar |
| slug | varchar, unique |
| image | varchar (nullable, storage path) |
| short_description | varchar(500), nullable |
| description | longtext (rich HTML content) |
| status | enum('published','draft') |
| views | bigint unsigned, default 0 |
| timestamps | |

## Notes

- Only an authenticated admin (logged-in user) can access `/admin/*` routes — enforced by the `auth` middleware in `routes/web.php`.
- Blog images are stored in `storage/app/public/blogs` and served via the `storage:link` symlink.
- Content editor uses CKEditor (CDN) so admins can format text, add headings, links, etc.
- To add more admin users later, just insert another row into `users` (or extend `AdminSeeder`).
